# 하루로그 · 기록→장면 디자인 결과 (NOTES)

`CLAUDE_DESIGN_PROMPT_scene.md` 요청에 대한 Claude Design 결과물입니다. 캔버스의 「기록 → 장면」 페이지에 같은 내용이 아트보드 5개로 올라가 있습니다.

> **앱에 적용하는 Claude에게**
> 1. **기존 데이터는 그대로 읽힙니다.** 새 필드는 모두 선택 사항이고, 값이 없으면 기본값으로 동작합니다(아래 1번 표).
> 2. 그림은 모두 SVG 벡터입니다. 좌표 기준은 아래와 같습니다.
>    - 논리 단위이고, **발밑 가운데가 (0,0)**, 오른쪽을 보는 모습입니다.
>    - 왼쪽은 `scale(-1,1)`로 뒤집어 씁니다.
>    - 외곽선은 `#3A2E2A`, 0.35~0.4입니다.
> 3. 색이 바뀌는 면은 `style="fill:var(--fur,#C98B5A)"`처럼 **CSS 변수에 기본값을 함께** 써 두었습니다. 캔버스에 `drawImage`로 그릴 때는 SVG 문자열에서 `var(--fur,#…)`를 고른 색으로 바꾼 뒤 이미지로 만드세요. `--fur-dark`, `--gear`도 같은 방식입니다.
> 4. 원본 도형 코드는 `generator/`(Python)에 있습니다. 좌표를 확인할 때 쓰세요.

---

## 1. 새 데이터 값 (모두 선택 사항, 하위 호환)

```js
profile.pets: [{ id, name, kind:'dog'|'cat', color:'#RRGGBB',
                 breed?: 'mix'|'poodle'|'shiba'|'dachshund'      // kind:'dog'
                        | 'mix'|'cheese'|'tuxedo'|'calico',      // kind:'cat'
                 gear?:  'collar'|'harness' }]
activity.scene: { m?, pets? }          // 변경 없음
```

| 필드 | 없을 때 | 값 목록 (라벨) |
|---|---|---|
| `breed` | `'mix'`(기존 기본 모습) | 강아지: `mix` 기본 · `poodle` 푸들 · `shiba` 시바 · `dachshund` 닥스훈트<br>고양이: `mix` 기본 · `cheese` 치즈 태비 · `tuxedo` 턱시도 · `calico` 삼색 |
| `gear` | `'collar'`(목줄) | `collar` 목줄 · `harness` 하네스 |

**털 색 → 진한 그림자색** (`--fur` → `--fur-dark`)

| 털 색 | 그림자색 |
|---|---|
| `#C98B5A` | `#9C6440` |
| `#F2EDE4` | `#CFC2AE` |
| `#3A2E2A` | `#221A17` |
| `#E8C79A` | `#C49C66` |
| `#9AA3B5` | `#6F7A8E` |

**무늬 색은 고정입니다.** 털 색을 바꿔도 아래 색은 그대로 유지됩니다.
- 시바: 볼·가슴·발이 흰색 `#FFF8EE`
- 턱시도: 입·가슴·발이 흰색
- 삼색: 주황 `#E8A05A`, 검정 `#3A2E2A`
- 치즈 태비: 줄무늬가 `--fur-dark`라서 털 색을 따라갑니다.

삼색 고양이는 털 색 `#F2EDE4`(흰색)를 추천값으로 보여 주세요.

## 3. 반려동물 그림

- **크기:** 몸 가로 12~15단위(닥스훈트는 18), 앉으면 키 약 14단위. viewBox는 `-12 -16 25 18`로 공통입니다.
- **걷기:** `walk-1 → 2 → 3 → 4` 순서로 6~8fps.
  - 대각선 다리가 짝으로 움직이고, 2·4번 프레임에서 앞으로 나가는 발이 0.9 들립니다.
  - 몸은 0.25 위아래로 움직입니다.
  - 강아지 꼬리는 프레임마다 각도가 바뀝니다(꼬리 흔들기 포함). 시바는 말린 꼬리, 푸들은 방울 꼬리입니다.
  - 고양이 꼬리는 S자로 살랑거립니다.
- **앉기(`sit`):** 캐릭터 옆에 함께 서 있을 때 씁니다.
- **엎드려 쉬기(`lie`):** 집 앞에서 쉴 때 씁니다. 눈을 감고 z 표시가 있습니다. z를 깜빡이게 하려면 `text` 요소의 투명도를 바꾸세요.
- **목줄·하네스:** 한 그림 안에 둘 다 있습니다(`g.gear-collar`, `g.gear-harness`). 하네스는 기본으로 숨겨 두었습니다.
  - 하네스로 보이게 하려면 문자열에서 `class="gear-harness" style="display:none"`를 `class="gear-harness"`로 바꾸고, `<g class="gear-collar">`를 숨기세요.
  - 장비 색은 `var(--gear,#E06A52)`이고, 금색 고리가 붙어 있습니다.
- **목줄 선:** 캐릭터 손에서 반려동물 `leashRing`까지 2차 곡선으로 그립니다.
  - 가운데가 2.5단위 처지게 합니다.
  - 바깥선은 `#3A2E2A` 0.9, 안쪽은 장비 색 0.5입니다.
  - 손 위치(키트 옆모습 기준): 걷기 프레임에서 약 `(1.8, -9.0)`, 서 있을 때 약 `(0, -8.6)`입니다.

## 4. 운동 소품 · 포즈

캐릭터(키트, 키 34) 기준점은 다음과 같습니다.
- 어깨 y = -14.5
- 손: 앞모습 (±4.9, -8.6)
- 눈: 앞모습 (±2.3, -21.2)
- 머리 꼭대기 y = -27.8

| `scene.m` | 그리는 순서(아래 → 위) | 움직임 |
|---|---|---|
| `strength` | `barbell-rack`(체육관 벽 쪽) · 캐릭터 앞모습 · `barbell` | 스쿼트: 캐릭터를 발밑 기준 `scaleY(0.86)`로 눌렀다 폅니다(1.2초 주기). 바벨 y = -14.5 × 그때의 scaleY. 앉았을 때 `sweat` |
| `run` | `treadmill-side` · 캐릭터 오른쪽 걷기 프레임 1↔2(10fps) · `sweat` | 캐릭터는 벨트 위 y = -2.6 |
| `swim` | `water-1/2`(0.5초마다 교대) · 캐릭터 앞모습(y +8, 어깨 아래 잘라냄) · `swim-cap` · `goggles` · `water-front` | 캐릭터 y가 ±0.6 출렁입니다 |
| `yoga` | `yoga-mat` · 다리(바지 색 타원, `compose.py → motion_yoga`) · 캐릭터 상반신(y +7.6, 허리 아래 잘라냄) · `yoga-aura` | 반짝임이 천천히 깜빡입니다 |
| `bike` | `spin-bike-back` · 캐릭터 오른쪽 모습(x -2.2, y -4.4) · `spin-bike-front-1/2`(페달 교대 0.25초) · `sweat` | 야외는 `bike-back` / `bike-front-1/2` |
| `boxing` | `sandbag-1/2/3`(캐릭터 앞 x +13) · 캐릭터 오른쪽 모습 · `gloves-guard` ↔ `gloves-jab` | 잽을 칠 때 샌드백이 1→2→3→2로 흔들립니다 |
| `meeting` | 화이트보드 · 캐릭터 · `fx/note` · `fx/wave` | 말하는 동안 wave 선이 깜빡입니다 |

## 5. 말풍선 · 이름표 (`ui/bubble.css`)

- **`.tag.say`**
  - 크림색 박스에 진한 테두리 1.5px, 아래 가운데 꼬리(`::after`)가 붙습니다.
  - 최대 폭 240px.
  - 등장할 때 `say-pop` 0.42s(작게 → 살짝 크게 → 원래 크기)로 톡 튀어나옵니다.
- **기분 변형:** 클래스 하나만 더하면 됩니다. 아이콘은 `<svg class="mood">`이고 마크업은 `bubble-demo.html`에 있습니다. 메모 키워드로만 고릅니다(AI 없음).

  | 클래스 | 고르는 키워드 | 모습 |
  |---|---|---|
  | `happy` | 좋다, 행복, 최고, 즐거 | 노란 말풍선 |
  | `tired` | 피곤, 힘들, 졸려, 야근 | 회색 말풍선이 살짝 출렁 |
  | `excited` | `!!`, 드디어, 완주, 대박 | 분홍 말풍선이 두 번 흔들림 |
  | `food` | 메모 없이 음식만 있을 때 “○○ 맛있다!” | 주황 말풍선 |

- **`.tag.pet`:** 갈색 라벨에 발바닥 아이콘이 붙습니다. 아이콘은 CSS 안에 data URI로 들어 있습니다.
- **접근성:** `prefers-reduced-motion`이면 애니메이션을 끕니다.

## 6. 입력 창 ‘장면’ 칸 · 설정 ‘반려동물’ 카드 (`ui/*.html`)

**장면 칸**
- 동작 select를 **아이콘 칩 그리드**로 바꿨습니다.
  - 첫 칩 ‘자동: ○○’은 점선 테두리이고, 두 칸을 차지합니다.
  - 나머지는 근력 운동·달리기·수영·요가·사이클·복싱·회의·발표·기본 동작입니다.
  - 모바일(≤480px)에서는 2열입니다.
- 함께 간 반려동물 칩에는 실제 앉은 그림(30×24) 썸네일이 들어갑니다.

**반려동물 카드**
- 한 줄 구성: 썸네일(앉기), 이름, ‘종류 · 모습 · 장비’, [수정] [삭제]
- 추가 폼에 새로 넣은 것:
  - 왼쪽에 **실시간 미리보기**(고른 모습·털 색으로 앉은 그림)
  - 종류 세그먼트, **모습 칩**(`breed`), 털 색 견본, **산책 장비 칩**(`gear`), [추가]
- 빈 상태: 자는 강아지와 고양이 일러스트 + “아직 함께 사는 친구가 없어요”

**영화 모드 카드**
- ‘동작’ 줄에 동작 아이콘이 들어간 초록 라벨을 씁니다.
- ‘함께’ 줄의 반려동물은 `.tag.pet`으로 표시합니다.

모든 버튼은 높이 36~40px 이상이고, 선택 상태는 `aria-pressed`로 표시합니다.

## 7. 함께한 사람과의 짧은 동작 (선택)

도착하고 1.2초 동안 한 번만 재생합니다. 친구가 옆에 서면 서로 마주 보게 합니다(왼쪽 사람은 right, 오른쪽 사람은 left).

| 동작 | 연출 |
|---|---|
| 손 흔들기 | `fx/wave`를 두 사람 사이에 0.6초 깜빡임. 처음 만날 때 |
| 하이파이브 | 두 사람이 0.3초 서로 2단위 다가갔다가 돌아오고, 그 사이에 `fx/spark` |
| 마주 보고 웃기 | 머리 위에 `fx/heart` 또는 `fx/note`. 메모가 happy일 때 |
| 반려동물 쓰다듬기 | 반려동물 `sit` + `fx/heart` |
| 헤어질 때 인사 | 한 명은 앞모습, 한 명은 뒷모습으로 걸어가며 `fx/wave` |

## 8. 적용 순서 (권장)

1. **반려동물 SVG 교체.** `breed`·`gear`가 없는 기존 데이터에서 `dog-*.svg` / `cat-*.svg`가 나오는지 확인합니다.
2. **목줄 선을 `leashRing` 좌표에 연결.**
3. **`bubble.css` 적용.** 기분 키워드 판별 함수를 추가합니다.
4. **운동 소품을 동작별로 레이어링**(4번 표 순서대로).
5. **장면 칸 칩 UI, 반려동물 카드(모습·장비·미리보기).**
6. **(선택) 함께하기 짧은 동작.**
